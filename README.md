# BRAINWAVE — 涂鸦风独立游戏标题界面

参照视频《Brainwave 独立游戏开发日志 #1》中游戏画面的 16:9 标题界面复刻。整站就是那一屏游戏画面：黑色背景居中铺开，不复刻视频平台的创作者信息、点赞收藏评论等栏目。

纯静态站点，零依赖、零构建：HTML + CSS + 原生 JS，GitHub Pages 直接托管。

在线地址：<https://yw-iris.github.io/brainwave/>

## 还原要点

| 元素 | 说明 |
| --- | --- |
| 斜切刷痕底板 | 硬边平行四边形（SVG 直线路径），上沿 `(0,124) → (1600,40)`、下沿 `(0,852) → (1600,408)`，与参考视频逐像素核对一致 |
| 三套主题配色 | 色值全部由参考图逐像素取样得到：**奶油粉**（`#7E86B2` 长春花蓝底 / `#FCECD9` 奶油带 / `#E73425` 正红油漆 / `#43527F` 靛蓝标题）、**蜜桃粉**（`#AFA8C2` 薰衣草底 / `#F4D9CE` 淡粉带 / `#D1385A` 玫红油漆 / `#5E3B4F` 深梅标题）、**撞色**（`#2F3A5C` 深板岩蓝底 / `#FCF9F6` 冷白带 / `#E8CE4E` 明黄油漆 / `#4A73D6` 亮蓝标题，最贴近原视频） |
| 角色插画 | 用户原画：珊瑚橙发、圆框眼镜女孩，裁成"大头出框"构图并做椭圆羽化，边缘化开融进奶油色带；替换 `assets/img/character.webp` 即可换图 |
| 喷射油漆 | JS 程序化生成（固定随机种子）：一把自喷口散开的**扇形**——48 条无缝堆叠的水平肋条构成扇心实心块（越靠中轴越长越厚），上下缘是带断口的干笔飞白，右缘伸出长短不一的"手指"，外圈只留 7 个圆点碎片与 8 块像素飞边，避免整体发脏 |
| 喷射揭示 | SVG 遮罩内的**椭圆**自嘴部向右单向扩张：`ry` 先行铺开成扇面，`rx` 再把扇形向右拉长，对齐视频 0.5→0.9s 的生长节奏 |
| 轨迹弧线 | 自角色嘴部掠向画面右上方的深蓝细弧，压在油漆之上 |
| BRAINWAVE 标题 | 自托管 Anton 字体 + 斜切压缩（`scaleX(.39)`），独立投影层做 3D 挤出 |
| 网点 / 扫描线 | CSS 叠层，还原视频的低分辨率网点印刷感 |

## 交互

菜单为两列栅格（左列内容页 / 右列功能页）：

- **ABOUT** —— 关于我（头像 + 简介 + 键值信息表）
- **LIKES** —— 喜欢的点（编号条目列表）
- **DISLIKES** —— 不喜欢的点（编号条目列表）
- **THEME** —— 切换下一套配色（带墨迹弹跳 + 标题错位过渡）
- **RECORDS** —— 档案面板（战绩表）
- **SETTINGS** —— 主题色板、音乐 / 音效 / 震动 / 自动轮播 / 全屏开关
- **NEW GAME** —— 开机动画：logo 闪白 → 进度条 → 按任意键返回
- **全屏观看** —— 右上角按钮（桌面端鼠标悬停浮现）/ 双击画面 / 按 `F` 键
- 键盘 `↑ ↓` 在列内移动、`← →` 跨列移动、`Enter` 确认、`Esc` 关闭面板
- 鼠标移动时插画位与标题有轻微视差

> ABOUT / LIKES / DISLIKES 三个详情页目前是**占位内容**（排版已就绪，直接改 `index.html` 里对应的 `.panel-about` / `.panel-likes` / `.panel-dislikes` 即可替换正文）。

## 入场动画时序

| 时间 | 动作 |
| --- | --- |
| 0.00s | 奶油斜切色带自左侧擦入 |
| 0.05s | 角色插画自左侧浮现 |
| 0.45s | **油漆自角色嘴部向右爆射**（椭圆遮罩自原点单向扩张：先细长射流，后炸开成墨团） |
| 0.80s | 轨迹深蓝弧线自嘴部掠向右上方（`stroke-dashoffset` 描线） |
| 0.95s | BRAINWAVE 标题缩放浮现（带轻微动态模糊） |
| 0.99s | 标题的深色投影延迟落地，形成 3D 挤出厚度 |
| 1.15s | NEW GAME 弹入（带回弹） |
| 1.30s | ABOUT / LIKES / DISLIKES 与 THEME / RECORDS / SETTINGS 两列逐条弹入 |
| 1.50s | 底部缩略图条与版本号淡入 |
| 之后 | 墨迹缓慢呼吸、标题微浮，主题每 4.2s 自动轮播 |

调试用参数：

```
index.html?frame=1.15   # 把画面定格在第 1.15 秒（逐帧核对用；油漆揭示由 JS 精确驱动 rx/ry）
index.html?slow=6       # 慢放 6 倍播放入场动画（演示用）
```

## 主题参数

支持 URL 参数锁定主题并关闭自动轮播，例如：

```
index.html?theme=cream     # 奶油粉（默认）
index.html?theme=peach     # 蜜桃粉
index.html?theme=night     # 撞色（深蓝+明黄）
```

未指定时使用 `localStorage` 中保存的上次选择，默认 `cream`。首页开启"自动轮播主题"后，每 4.2 秒在奶油粉 → 蜜桃粉 → 撞色之间循环。
