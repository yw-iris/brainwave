# BRAINWAVE — 涂鸦风独立游戏标题界面

参照视频《Brainwave 独立游戏开发日志 #1》中游戏画面的 16:9 标题界面复刻。整站就是那一屏游戏画面：黑色背景居中铺开，不复刻视频平台的创作者信息、点赞收藏评论等栏目。

纯静态站点，零依赖、零构建：HTML + CSS + 原生 JS，GitHub Pages 直接托管。

## 还原要点

| 元素 | 说明 |
| --- | --- |
| 斜切刷痕底板 | SVG 路径绘制的不规则斜切色带，上沿接近平直、下沿为 −14° 斜线，左下角几乎贴边 |
| 三套主题配色 | 奶油红（奶油 / 长春花蓝 / 正红 / 靛蓝字）、桃粉玫红（桃白 / 薰衣草紫 / 玫红 / 墨色字）、夜紫金（奶油 / 夜紫 / 明黄 / 玫红字） |
| 角色插画 | 珊瑚橙发、圆框眼镜的日系插画，透明底 WebP（277KB），贴合奶油色带并随主题换底色；替换 `assets/img/character.webp` 即可换成自己的原画 |
| 涂鸦墨迹 | JS 程序化生成（固定随机种子）：喷射尾迹笔触、撕裂墨块、飞溅液滴、干笔纹理；用 SVG 遮罩圆自原点扩散实现"喷出"过程 |
| BRAINWAVE 标题 | 自托管 Anton 字体 + 斜切压缩，独立投影层做 3D 投影与延迟落地 |
| 网点 / 扫描线 | CSS 叠层，还原视频的低分辨率网点印刷感 |

## 交互

- **THEME** —— 切换下一套配色（带墨迹弹跳 + 标题错位过渡）
- **RECORDS** —— 档案面板（战绩表）
- **SETTINGS** —— 主题色板、音乐 / 音效 / 震动 / 自动轮播 / 全屏开关
- **NEW GAME** —— 开机动画：logo 闪白 → 进度条 → 按任意键返回
- **全屏观看** —— 右上角按钮（桌面端鼠标悬停浮现）/ 双击画面 / 按 `F` 键
- 键盘 `↑ ↓` 移动焦点、`Enter` 确认、`Esc` 关闭面板
- 鼠标移动时插画位与标题有轻微视差

## 入场动画时序

| 时间 | 动作 |
| --- | --- |
| 0.00s | 白色斜切色带自左侧擦入 |
| 0.15s | **黄色油漆自画面左侧一点向右喷射爆开**（SVG 遮罩圆自原点扩散，逐帧"喷"出墨迹、方向性笔触与液滴） |
| 0.80s | 喷射轨迹的背景色弧线自下向左上画出（`stroke-dashoffset` 描线） |
| 0.95s | BRAINWAVE 标题自右侧砸落（带回弹 + 动态模糊） |
| 1.06s | 标题的深色投影延迟 0.1s 落地，形成撞击感 |
| 1.30s | 标题落点扩散出漫画式冲击波环 |
| 1.40s | NEW GAME 弹入（带回弹） |
| 1.55s | THEME / RECORDS / SETTINGS 逐条弹入 |
| 1.85s | 底部缩略图条与版本号淡入 |
| 之后 | 墨迹缓慢呼吸、标题微浮，主题每 4.2s 自动轮播 |

调试用参数：

```
index.html?frame=1.15   # 把入场动画定格在第 1.15 秒（逐帧核对用，WAAPI 精确定位）
index.html?slow=6       # 慢放 6 倍播放入场动画（演示用）
```

## 主题参数

支持 URL 参数锁定主题并关闭自动轮播，例如：

```
index.html?theme=cream     # 奶油红（默认）
index.html?theme=peach     # 桃粉玫红
index.html?theme=night     # 夜紫金
```

未指定时使用 `localStorage` 中保存的上次选择，默认 `cream`。首页开启"自动轮播主题"后，每 4.2 秒在奶油红 → 桃粉玫红 → 夜紫金之间循环。
